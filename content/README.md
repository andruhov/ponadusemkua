# Тексти сайту

Усі написи, які бачить відвідувач, лежать **лише тут**. Код у `src/` їх тільки читає.

| Файл | Що міняти |
|---|---|
| `strings.jsonc` | Назва, абзаци, кнопки, меню — українською й англійською |
| `donate.jsonc` | Банки Monobank, картки, крипта, PDF рахунків |
| `socials.jsonc` | Посилання на соцмережі |
| `gallery-captions.txt` | Підписи фото в розділі «Наша робота» |

## Правила

1. Не чіпайте файли в `src/`, якщо треба змінити лише текст або реквізит.
2. У `.jsonc` можна писати коментарі `//` і `/* … */`. Коми в кінці списків дозволені.
3. Кожне двомовне поле має **обидва** ключі: `"uk"` і `"en"`.
4. Лапки всередині тексту екрануйте: `"ГО «Миколаїв»"` — ок; якщо треба `"`, пишіть `\"`.
5. Фото кладіть у `public/work/` (сітка) і `public/slideshow/` (герой). Підписи — сюди, у `gallery-captions.txt`.
6. Після збереження dev-сервер оновить сторінку сам. Для GitHub Pages потрібна збірка.

Деталі формату — коментарі на початку кожного файлу.
